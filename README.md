# 📝 Notes App

A clean and responsive notes application built with HTML, CSS and JavaScript.

## Features

- Create notes
- Search notes
- Delete notes
- Notes count
- Automatic local storage
- Data remains after refreshing
- Responsive design
- Clean and modern interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
